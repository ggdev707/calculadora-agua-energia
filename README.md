Calculadora de Consumo de Água e Energia

Sistema web que estima o gasto mensal de uma residência com água e energia elétrica a partir dos hábitos informados e mostra dicas práticas para economizar.

Acesse online: https://ggdev707.github.io/calculadora-agua-energia/

Funcionalidades
Estimativa do gasto mensal em reais, com total, subtotais de água e energia e uma barra mostrando a proporção entre os dois.
Detalhamento por item (banhos, lâmpadas, ar-condicionado, geladeira etc.), do maior gasto para o menor.
Tarifas editáveis (R$/kWh e R$/m³), para usar os valores reais da conta da família.
13 dicas de economia; a página mostra 3 delas, escolhidas conforme os hábitos informados. O botão "Outras dicas" troca a seleção.
Os dados ficam salvos no navegador (Local Storage), então não se perdem ao recarregar a página.
Layout responsivo (celular e computador), com modo claro e escuro automático.
Tecnologias

HTML5, CSS3 e JavaScript puro, sem frameworks nem dependências. A fonte Manrope é carregada do Google Fonts (se estiver sem internet, o navegador usa a fonte do sistema).
